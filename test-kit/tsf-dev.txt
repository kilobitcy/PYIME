PYIME 新 TSF 前端 实机验证清单(不经安装器)

准备:把 tsf-dev.zip 解压到 C:\pyime-tsf-dev(路径不要有中文或空格)。
在该目录的地址栏输入 cmd 回车,打开普通(非管理员)命令行窗口,以下命令都在这个窗口里执行。
每项记"通过 / 不通过 + 现象";不通过的附 %LOCALAPPDATA%\PYIME\tsf.log 与 log.txt。
注意:旧的 PIME 版 PYIME 可以保留;两者共用 %LOCALAPPDATA%\PYIME\user.txt,
同时用两边选词时,一边会因"文件被外部修改"暂停写盘(学习只留在内存),属预期,不是故障。

一、安装
 1. 执行 tsf-dev.bat install,同意管理员授权,窗口显示 Installed.
 2. 设置 → 时间和语言 → 语言和区域 → 中文 → 键盘:出现一个新的"PYIME 拼音"(列表末尾);没有就点"添加键盘"加上。
 3. 任务管理器"详细信息"里有两个 pyime-server.exe(监护 + 工作进程);登录桌面、执行命令时都没有弹出黑色窗口。

二、打字(切到新装的那个"PYIME 拼音")
 4. 记事本、Edge、Chrome、Word、微信:各打 ceshi 选"测试",再打一句整句,上屏正确。
 5. 一个 32 位程序(如 32 位的 WinRAR/旧版软件)里同样能打字。
 6. 候选窗外观与 0.1.15 一致(绿色选中块、灰色序号);单击 Shift 切中英;托盘"中/英"图标与右键菜单正常。
 7. 开始菜单搜索框、资源管理器地址栏:能否打中文(验证包不在 Program Files,沙箱应用打不出可先记现象,正式包再验)。

三、故障恢复
 8. 任务管理器结束两个 pyime-server.exe 中内存较大的那个(工作进程),马上在记事本打字:不卡顿,字母直接出现;
    几秒后再打,恢复中文候选。
 9. 打着拼音(候选窗开着)时结束工作进程,再按一个字母:候选窗消失,带下划线的拼音被清掉,文档里不残留拼音字母(只多出刚按的那个字母或什么都不多)。
10. 执行 tsf-dev.bat stop 后在记事本连续打字:每个键没有明显延迟,字母直接出现。
11. 执行 tsf-dev.bat start,30 秒内打字恢复中文。
12. 打开 %LOCALAPPDATA%\PYIME\tsf.log:有"连接 PYIME 服务端失败""已连接 PYIME 服务端""请求失败"之类记录,
    只有进程名和错误码,没有你打的拼音或文字。

四、卸载
13. 执行 tsf-dev.bat uninstall,同意授权,显示 Uninstalled.;新装的"PYIME 拼音"不再可用,旧的 PIME 版照常。
