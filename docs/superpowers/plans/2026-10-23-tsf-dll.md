# TSF DLL 收编与直连改造 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 PIME 1.3.0 的 TSF DLL 源码(libIME2 + PIMETextService + jsoncpp)收编进本仓库 `tsf/` 并自行构建;再把 DLL 改为直连 PYIME 自有服务端的命名管道(超时、退避、断线清理、本地日志、新 GUID),附不依赖安装器的实机验证包。

**Architecture:** 第 1 阶段(Task 1–2)只搬源码、换构建脚本,产物与旧 `build-pime-dll.sh` 逐字节同代码,装进现有 PIME 实测无回归。第 2 阶段(Task 3–7)只改 `PIMEClient`(IPC 层)、`PIMEImeModule`/`DllEntry`(注册信息)与少量新文件;按键→JSON、JSON→组字/候选/托盘按钮的逻辑不动,因此服务端 `session.rs` 不用改。

**Tech Stack:** C++17,mingw-w64 交叉编译(`x86_64-w64-mingw32-g++` / `i686-w64-mingw32-g++`,线程模型 win32,无 `std::mutex`,用 SRWLOCK),windres,bash;纯逻辑单测用本机 `g++`。

## Global Constraints

- 设计文档:`docs/superpowers/specs/2026-10-23-tsf-frontend-design.md`(组件 1、实施顺序第 1、3 步)。
- 管道 `\\.\pipe\<GetUserNameW 用户名>\PYIME`,消息模式;一条消息 = 一个 UTF-8 JSON 请求(字段与现 PIME 协议相同,可带结尾 `\n`),回复一条 JSON 消息(带 `success`、`seqNum`)。连接断开 = 会话结束。
- 服务端 `pyime-server.exe` 位于 DLL 上一级目录;参数 `--supervise` 监护、`--worker` 管道服务、`--quit` 通知退出;无参数 = 旧 PIME stdin 模式。**DLL 不拉起服务端。**
- 互斥量 `Local\PYIME-supervisor`,退出事件 `Local\PYIME-quit`(本计划只在 `tsf-dev.bat` 里经 `--quit` 间接使用)。
- 安装目录 `$PROGRAMFILES64\PYIME`,DLL 在 `x64\PYIME.dll`、`x86\PYIME.dll`,图标 `icons\` 在 exe 同目录。
- 新 CLSID `{8298C4A9-D032-442A-90AE-1983DF71CDBE}`,语言配置 GUID `{87977804-6ADE-4B62-8715-4B1C29435A52}`,名称 `PYIME 拼音`,LangID 0x0804(locale `zh-Hans-CN`,fallback `zh-CN`,与现 `installer/input_methods/pyime/ime.json` 一致)。
- 显示属性 GUID 同时换新:`{F90B2442-FAAA-4455-A719-8ADC19CA3D39}`(原 `libIME2/src/ImeModule.cpp:53` 与官方 PIME 相同,两者并存时会冲突)。
- DLL 日志 `%LOCALAPPDATA%\PYIME\tsf.log`(路径经 `SHGetKnownFolderPath`),存在 `%LOCALAPPDATA%\PYIME\log.disabled` 则不写;只记连接/超时/断线/退避与宿主进程名,**不记按键**。
- 超时:连接 `WaitNamedPipe` 200ms 一次;请求 2s(含 `init`);超时收尾 `CancelIoEx` → `GetOverlappedResult(bWait=TRUE)` → 才关句柄;收发缓冲区为 `Client` 成员。
- 退避:连接失败、请求超时、断线共用一个计数,1s 起倍增,上限 30s,成功一次清零;退避期内按键直接放行。
- 不做管道对端校验(删掉空实现 `isPipeCreatedByPIMEServer`)。
- 收编代码按原许可证(LGPL)分发修改版,保留原版权头;改过的文件在头部版权块下加一行 `// PYIME 修改:<一句话>`,改动处注释以 `PYIME:` 开头。新文件用中文注释。
- 链接:`-static -static-libgcc -static-libstdc++`,objdump 不得出现 `libgcc`/`libstdc`/`libwinpthread`。
- 批处理 `.bat` 纯 ASCII + CRLF;验证清单 `.txt` 为 UTF-8 BOM + CRLF。
- 单次写文件 ≤150 行(用户全局规则);只在本计划列出的文件上动手;push/tag/发布前先问用户。
- 无 Windows 环境:C++ 改动的本机验收 = 交叉编译通过 + objdump 依赖/导出检查 + 纯逻辑单测;其余标"实机验证项",由用户按清单验证。

- [ ] **Step 4: 写 `scripts/build-tsf.sh`**

```bash
#!/usr/bin/env bash
# 用 mingw-w64 交叉编译收编在 tsf/ 的 TSF 文本服务 DLL(x64 + x86),输出到 target/tsf/{x64,x86}。
# 源码来源与许可证见 tsf/README.md。用法:scripts/build-tsf.sh
set -euo pipefail
cd "$(dirname "$0")/.."
ROOT=$PWD
SRC=$ROOT/tsf
OUTDIR=$ROOT/target/tsf
DLL=PIMETextService.dll
PIME_SRCS="DllEntry PIMEClient PIMEImeModule PIMELangBarButton PIMETextService"

# 头文件大小写垫片(源码按 Windows 大小写不敏感写 include)
SHIM=$(mktemp -d)
trap 'rm -rf "$SHIM"' EXIT
INC=/usr/x86_64-w64-mingw32/include
for h in ObjBase.h OleCtl.h Shellapi.h ShlObj.h Shlwapi.h Unknwn.h VersionHelpers.h Windows.h Winnls.h; do
  ln -s "$INC/${h,,}" "$SHIM/$h"
done
touch "$SHIM/Ctffunc.h"  # 所需声明已在 tsf_compat.h
ln -s "$SRC/libIME2/src/Window.h" "$SHIM/window.h"
ln -s "$SRC/libIME2" "$SHIM/LibIME2"

build() {  # build <x64|x86>
  local T OBJ OUT
  case $1 in x64) T=x86_64-w64-mingw32 ;; x86) T=i686-w64-mingw32 ;; esac
  OBJ=$SHIM/obj-$1; OUT=$OUTDIR/$1; mkdir -p "$OBJ" "$OUT"
  local CXXFLAGS="-std=c++17 -O2 -DUNICODE -D_UNICODE -DWIN32_LEAN_AND_MEAN -D_WIN32_WINNT=0x0600 -DNDEBUG
    -include tsf_compat.h -I$SHIM -I$SRC -I$SRC/libIME2/src -I$SRC/jsoncpp/include -I$SRC/PIMETextService"
  for f in ImeModule libIME TextService KeyEvent EditSession DisplayAttributeInfo DisplayAttributeInfoEnum \
      DisplayAttributeProvider LangBarButton Utils DrawUtils Window ImeWindow MessageWindow CandidateWindow; do
    $T-g++ $CXXFLAGS -c "$SRC/libIME2/src/$f.cpp" -o "$OBJ/ime_$f.o"
  done
  for f in json_reader json_value json_writer; do
    $T-g++ $CXXFLAGS -c "$SRC/jsoncpp/src/lib_json/$f.cpp" -o "$OBJ/json_$f.o"
  done
  for f in $PIME_SRCS; do
    $T-g++ $CXXFLAGS -c "$SRC/PIMETextService/$f.cpp" -o "$OBJ/pime_$f.o"
  done
  sed -e 's/@PIME_VERSION_MAJOR@/1/g;s/@PIME_VERSION_MINOR@/3/g;s/@PIME_VERSION_PATCH@/0/g' \
    "$SRC/PIMETextService/PIMETextService.rc.in" > "$OBJ/PIMETextService.rc"
  $T-windres -I"$SRC/PIMETextService" -I"$SHIM" "$OBJ/PIMETextService.rc" -O coff -o "$OBJ/res.o"
  # --kill-at:x86 导出名去掉 stdcall 修饰,与 .def 一致
  $T-g++ -shared -static -static-libgcc -static-libstdc++ -s -Wl,--kill-at -Wl,--subsystem,windows \
    -o "$OUT/$DLL" "$OBJ"/*.o "$SRC/PIMETextService/PIMETextService.def" \
    -lole32 -loleaut32 -luuid -lshlwapi -lgdi32 -luser32 -ladvapi32 -lshell32
  if $T-objdump -p "$OUT/$DLL" | grep -E 'DLL Name: (libgcc|libstdc|libwinpthread)'; then
    echo "$1 DLL 依赖了 mingw 运行库,中止" >&2; exit 1
  fi
  for sym in DllGetClassObject DllCanUnloadNow DllRegisterServer DllUnregisterServer; do
    $T-objdump -p "$OUT/$DLL" | grep -qw "$sym" || { echo "$1 DLL 缺导出 $sym,中止" >&2; exit 1; }
  done
}
build x64
build x86
ls -l "$OUTDIR"/*/"$DLL"
```

```cpp
// PIME::Backoff 的本机单测(Linux g++ 编译运行,由 scripts/build-tsf.sh 调用)。
#include "Backoff.h"
#include <cstdio>

static int failures = 0;
#define CHECK(cond) do { if (!(cond)) { std::printf("失败 %s:%d: %s\n", __FILE__, __LINE__, #cond); ++failures; } } while (0)

int main() {
    using PIME::Backoff;
    {   // 初始不退避
        Backoff b;
        CHECK(!b.blocked(0));
        CHECK(b.delayMs() == 0);
    }
    {   // 首次失败退避 1s,到点即可重试
        Backoff b;
        CHECK(b.fail(100) == 1000);
        CHECK(b.blocked(100));
        CHECK(b.blocked(1099));
        CHECK(!b.blocked(1100));
    }
    {   // 连续失败倍增,封顶 30s
        Backoff b;
        const unsigned expect[] = {1000, 2000, 4000, 8000, 16000, 30000, 30000};
        for (unsigned e : expect) CHECK(b.fail(0) == e);
    }
    {   // 成功一次清零,下次失败从 1s 重新开始
        Backoff b;
        b.fail(0);
        b.fail(0);
        b.succeed();
        CHECK(!b.blocked(0));
        CHECK(b.fail(0) == 1000);
    }
    if (failures == 0) std::printf("backoff_test: 全部通过\n");
    return failures == 0 ? 0 : 1;
}
```

// 连接失败、请求超时、断线共用一个计数:首次失败后 1s 内不再尝试,
// 之后每次失败间隔翻倍,上限 30s;成功一次即清零。时间单位毫秒,由调用方传入(GetTickCount64)。
#ifndef PYIME_BACKOFF_H
#define PYIME_BACKOFF_H

#include <cstdint>

namespace PIME {

class Backoff {
public:
    static constexpr uint32_t kFirstMs = 1000;
    static constexpr uint32_t kMaxMs = 30000;

    // nowMs 时刻是否仍在退避期内(此时不应尝试连接)
    bool blocked(uint64_t nowMs) const { return nowMs < retryAfterMs_; }

    // 记一次失败,返回本次退避时长
    uint32_t fail(uint64_t nowMs) {
        delayMs_ = delayMs_ == 0 ? kFirstMs : (delayMs_ >= kMaxMs / 2 ? kMaxMs : delayMs_ * 2);
        retryAfterMs_ = nowMs + delayMs_;
        return delayMs_;
    }

    void succeed() {
        delayMs_ = 0;
        retryAfterMs_ = 0;
    }

    uint32_t delayMs() const { return delayMs_; }

private:
    uint64_t retryAfterMs_ = 0;
    uint32_t delayMs_ = 0;
};

}

#endif

static std::wstring logDir() {

    std::wstring dir;

        dir = std::wstring(path) + L"\\PYIME";

static std::string processName() {
    wchar_t buf[MAX_PATH] = {0};
    DWORD n = ::GetModuleFileNameW(nullptr, buf, MAX_PATH);
    const wchar_t* name = buf;
    for (DWORD i = 0; i < n; ++i) {
        if (buf[i] == L'\\')
            name = buf + i + 1;

    return utf16ToUtf8(name);

    if (dir.empty() || ::GetFileAttributesW((dir + L"\\log.disabled").c_str()) != INVALID_FILE_ATTRIBUTES)
        return;

    std::wstring path = dir + L"\\tsf.log";

OVERLAPPED* Client::startIo() {

// PYIME:等待 startIo() 发起的操作;started 为 WriteFile/ReadFile 的返回值。
// 成功返回 true(error 为 ERROR_SUCCESS,或 ERROR_MORE_DATA 表示消息还没读完);
// 超时则 CancelIoEx,并用 GetOverlappedResult(bWait=TRUE) 等取消真正完成后才返回 false(error = WAIT_TIMEOUT),
// 此后 readBuf_/overlapped_ 才可复用——否则内核可能迟到写入,破坏宿主进程内存。
bool Client::finishIo(BOOL started, DWORD timeoutMs, DWORD& transferred, DWORD& error) {
    transferred = 0;
    error = started ? ERROR_SUCCESS : ::GetLastError();
    if (!started && error != ERROR_IO_PENDING && error != ERROR_MORE_DATA)
        return false;  // 没有挂起的 I/O
    if (error == ERROR_IO_PENDING && ::WaitForSingleObject(ioEvent_, timeoutMs) != WAIT_OBJECT_0) {
        ::CancelIoEx(pipe_, &overlapped_);
        ::GetOverlappedResult(pipe_, &overlapped_, &transferred, TRUE);
        error = WAIT_TIMEOUT;
        return false;
    }
    if (::GetOverlappedResult(pipe_, &overlapped_, &transferred, FALSE)) {
        error = ERROR_SUCCESS;
        return true;
    }
    error = ::GetLastError();
    return error == ERROR_MORE_DATA;
}

// PYIME:写一条请求消息、读完整条回复消息,总耗时不超过 timeoutMs。失败时 lastIoError_ 记错误码。
bool Client::callRpcPipe(const std::string& serializedRequest, std::string& serializedReply, DWORD timeoutMs) {
    if (pipe_ == INVALID_HANDLE_VALUE || !ioEvent_) {
        lastIoError_ = ERROR_INVALID_HANDLE;
        return false;
    }
    const ULONGLONG deadline = ::GetTickCount64() + timeoutMs;
    auto remaining = [deadline]() -> DWORD {
        ULONGLONG now = ::GetTickCount64();
        return now >= deadline ? 0 : DWORD(deadline - now);
    };
    DWORD transferred = 0;
    BOOL started = ::WriteFile(pipe_, serializedRequest.data(), DWORD(serializedRequest.size()), nullptr, startIo());
    if (!finishIo(started, remaining(), transferred, lastIoError_))
        return false;
    for (;;) {
        started = ::ReadFile(pipe_, readBuf_, sizeof(readBuf_), nullptr, startIo());
        if (!finishIo(started, remaining(), transferred, lastIoError_))
            return false;
        serializedReply.append(readBuf_, transferred);
        if (lastIoError_ != ERROR_MORE_DATA)
            return true;
    }
}

// PYIME:只连一次、最多等 kConnectTimeoutMs;失败进入退避,退避期内直接返回 false(按键放行)。
bool Client::waitForRpcConnection() {

        return true;
