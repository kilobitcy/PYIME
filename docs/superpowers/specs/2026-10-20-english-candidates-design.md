# 英文候选(IT/科技词补全) 设计

日期:2026-10-20 · 基于 main = 2b0bad0

## 背景

- 用户常在中文里夹 IT 英文词(subagent、playwright、GitHub)。现状只能单击 Shift 切英文,
  或打完字母按回车原样上屏小写(`flush_raw`);拼音切不通时还会冒出一串乱拼的中文。
- 本次新增价值:前缀补全、规范大小写(`github` → `GitHub`)、选词学习。
- rime-ice `en_dicts/en.dict.yaml`(约 2.3 万行)与 `en_ext.dict.yaml`(约 2600 行)同为 GPL-3.0,
  格式 `词⇥编码`,**无词频**(按字母序);缺 `subagent` 等新词。

## 方案

引擎新增独立模块 `english.rs`:启动时载入纯文本词表到内存(有序 Vec,二分查前缀),
`candidates_after` 中作为第四种来源 `Source::English` 合并。不动拼音 fst 与现有排序。
否决:英文编进 `pyime.dict`(键空间与拼音混杂);只在后端做(破坏分层,回归测不到)。

## 1. 词表

- 来源与档位(数字越小越优先):
  - 0:项目自带 IT 词表 `installer/en_it.txt`、用户词表 `%LOCALAPPDATA%\PYIME\en.txt`
  - 1:rime-ice `en_ext.dict.yaml`
  - 2:rime-ice `en.dict.yaml`
- 键:
  - rime-ice 取编码列,转小写;编码含非字母(如 `K8s`)的行跳过。
  - 自带/用户词表一行一个词,`#` 开头为注释;键取词中字母转小写(`Claude Code` → `claudecode`)。
    键为空的行跳过。
- 打包:`scripts/package.sh` 调新工具 `pyime-en-build` 把 rime 两表与 IT 表合并为 `pyime.en`
  (每行 `键⇥词⇥档位`,同键同词保留最小档位),放 `server.exe` 同目录。
- 后端启动时载入 `pyime.en` 与用户 `en.txt`;任一缺失或读失败则跳过该来源,记日志,不影响中文。

## 2. 何时出英文、排第几

输入仅对当前待转换段(`input`,全小写字母)。定义"拼音通":中文候选中存在 `consumed == input.len()`
的整段词或整句。

- **拼音不通**(如 `playwright`、`subagen`):
  - 英文候选排在最前:完全匹配的词,然后补全(输入 ≥ 4 字母才补全),英文合计至多 3 条;
  - 其后接原有中文候选。
- **拼音通**(如 `change`、`hang`):
  - 只出完全匹配的英文词,插在第 3 位(中文不足 2 条则接在末尾);不补全;
  - 输入长度 ≤ 3(`go`、`me`)不出英文。
- **学过的英文**(定义见第 3 节防错字规则)且键入恰为这串输入的,不受上述长度/补全限制,
  按 `UserModel::bonus` 与中文候选中最高的学习加分比较,更高则排第 1 位,否则按上述规则落位。
- 英文候选之间排序:学过的(按加分) > 档位 0 > 1 > 2;同档内完全匹配优先,再按词长升序,再按字母序。
- 与中文候选同文字去重沿用现有逻辑;英文候选 `consumed = input.len()`,`cuts` 为空,`fuzzy = 0`。

## 3. 选中与学习

- 选中英文候选:走现有 `learn(input, 词)`,存入 `user.txt` 的 `(键入, 词)` 行,不改存盘格式。
  学过的英文词还作为该前缀的补全来源(新增 `UserModel` 方法:列出键入以 `input` 开头且词为纯 ASCII 的项)。
- 回车自动学习:拼音不通、全是字母、≥ 4 字母时按回车原样上屏,记一次 `learn(input, input)`。
  防错字规则:**词表外**的词,`(键入, 词)` 计数 ≥ 2 才算"学过"(才出补全/候选、才享第 2 节的学习排序);
  词表内的词计数 ≥ 1 即算。这样 `zhegnshi` 之类错字回车一次不会冒出来。
- 删除:组字中 Ctrl+Shift+数字删除该候选的个人学习(沿用 `forget`)。
- 输入日志照常记录英文候选与所选,`pyime-misses`/`pyime-replay` 无需特殊处理。

## 4. 不做

- 中英混输一串(`yongplaywrightceshi`):需分段,先上屏"用"再打 `playwright`。
- 英文词频表;首字母自动大写;上屏后自动补空格。

## 5. 测试与评测

- 引擎单测(小词表构造):
  - 拼音不通时英文排首位,补全至多 3 条,< 4 字母不补全;
  - 拼音通时完全匹配的英文在第 3 位、≤ 3 字母不出、不补全;
  - 学过的英文按加分提前;档位与长度排序;
  - 回车学习计数 1 次不出现、2 次出现;`forget` 后消失。
- 词表解析单测:编码含数字跳过、注释/空行跳过、`Claude Code` 键为 `claudecode`。
- 后端单测:回车自动学习的条件(拼音通/不足 4 字母/含非字母时不学)。
- 回归对照:`Source::English` 新增"英文"桶,补用例 `subagent→subagent`、`playwright→Playwright`、
  `github→GitHub`、`change→嫦娥`(实现时以现有首位为准,要求首位不变)。现有各桶不得退步,用 `PYIME_RANKS_BASE` 逐例比对。

## 风险

- 无词频,普通英文词补全可能不准(`appl` 先出 `Apple`);IT 词有档位 0 兜底,待日志暴露再考虑词频表。
- "拼音通"的输入里英文占第 3 位会把原第 3 位中文挤到第 4;仅在完全匹配且 ≥ 4 字母时发生。
